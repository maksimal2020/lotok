## До коммерческого запуска (обязательно)
1. Юридическая проверка (docs/LEGAL.md): ПДн, ОРИ, реклама/ОРД, оферта, схема приёма оплаты за товары продавцов.
2. Подключение и проверка ЮKassa на тестовом магазине → боевой; выбор схемы выплат продавцам (сплитование/«Безопасная сделка»), реализация выплат и сверок.
3. SMS-шлюз, SMTP-домен с DKIM, Expo Push с ключами APNs/FCM.
4. 2FA для сотрудников, WAF/anti-bot, капча на регистрацию/SMS при аномалиях.
5. Нагрузочное тестирование (k6) и настройка лимитов; pentest.
6. Нативные сборки iOS/Android через EAS, тестирование на устройствах, публикация в сторах.
7. Интеграция служб доставки (СДЭК/Boxberry/Почта России).

## Следующие продуктовые итерации
- Мобильное приложение: редактирование объявлений, фильтры по характеристикам, вложения в чате, настройки уведомлений, deep links из push.
- Веб: перетаскивание фото на мобильных (touch), карта выдачи с кластеризацией, сравнение объявлений, черновики автосохранением.
- Поиск: управляемые синонимы из админки, кластеризация точек на карте, «похожие объявления».
- Рекомендации: коллаборативная фильтрация (после накопления данных и правового основания).
- Вход через VK ID / Яндекс ID / Госуслуги.
- Компании: множественные менеджеры объявлений, API для выгрузки (XML/YML-фиды), CRM-интеграции.
- Модерация: классификатор изображений, проверка дублей по perceptual hash.
- Вынести UI-кит веба/админки в `packages/ui`.
- Партиционирование `messages`, `audit_logs`, `security_events`.
