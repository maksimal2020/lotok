# Фактический прогресс

Обновлено: 2026-11-19. Отметки ниже подтверждены кодом и запуском тестов в этой сессии (см. «Результаты проверок»).

## Реализовано

### Backend (`apps/api`)
- [x] Конфигурация с валидацией (zod), запрет dev-секретов/inline-очереди/тестовых эндпоинтов в production
- [x] Схема PostgreSQL — 50 таблиц, внешние ключи, CHECK, индексы (GIN FTS, pg_trgm), 3 миграции
- [x] Авторизация: email+пароль (argon2id), подтверждение email, SMS-вход, восстановление, ротация refresh + reuse detection, сессии, выход со всех устройств, защита от перебора
- [x] Пользователи: профиль, публичная страница, настройки уведомлений (матрица группа×канал), push-токены, блокировка собеседников, удаление аккаунта (обезличивание)
- [x] Компании: ИНН (контрольная сумма), участники, проверка модератором
- [x] Категории/характеристики/регионы, управляемые из админки; наследование характеристик; зависимые справочники (марка→модель)
- [x] Медиа: сигнатуры, лимиты, ClamAV-адаптер, sharp (3 размера WebP, удаление EXIF), приватные ссылки
- [x] Объявления: черновик → модерация → публикация, все переходы жизненного цикла с проверкой, история, оптимистическая блокировка, квоты бесплатных публикаций и платные слоты (с возвратом при отклонении), автомодерация, статистика (просмотры/контакты/избранное), телефон по запросу, срок размещения
- [x] Поиск: PostgreSQL FTS + триграммы и OpenSearch (оба проверены тестами), фильтры по характеристикам, цена, город с подрегионами, радиус, bbox/карта, сортировки, фасеты, автодополнение, синонимы брендов, ё→е, премиум-блок отдельно от органики
- [x] Избранное, сохранённые поиски с уведомлениями о новых объявлениях, детерминированные рекомендации, история просмотров (очищаемая)
- [x] Мессенджер: REST + Socket.IO (Redis adapter/emitter), статусы доставки/прочтения, вложения (изображения/документы), архив, поиск, блокировка, жалобы на сообщения, идемпотентность `clientMessageId`, счётчики непрочитанного
- [x] Уведомления: in-app + WebSocket, email, push, SMS — по настройкам пользователя
- [x] Отзывы (после завершённой сделки или переписки), рейтинг; жалобы с автоповторной модерацией по порогу
- [x] Заказы: резерв количества под блокировкой, самовывоз/доставка, все статусы и действия сторон, авто-завершение, отмена неоплаченных, автоматический возврат при отмене оплаченного, возврат после доставки
- [x] Платежи: абстракция провайдера, mock-провайдер (sandbox) с подписанными webhook, адаптер ЮKassa, идемпотентность, журнал событий, сверка, возвраты, двойная запись (ledger) с разделением средств продавцов, выручки и бонусов
- [x] Монетизация: каталог услуг (поднятие, многодневное поднятие, выделение, премиум, доп. публикация, пакет, PRO, расширенная статистика), бонусы, рекламные размещения с erid
- [x] Админ API: дашборд, аналитика, пользователи (блокировка, роли, бонусы), компании, модерация, жалобы, отзывы, категории/характеристики, регионы, тарифы, реклама, платежи/возвраты, сверка ledger, заказы, журнал аудита, события безопасности, настройки платформы, стоп-слова, переиндексация
- [x] Health/readiness/metrics (Prometheus), JSON-логи с request-id
- [x] Worker: BullMQ-очереди и расписания (истечение объявлений, продвижения, заказы, сверка платежей, сохранённые поиски, переиндексация, затухание интересов)

### Web (`apps/web`) — все обязательные страницы ТЗ
Главная, каталог, категория (SSR, хлебные крошки, SEO), поиск с динамическими фильтрами (desktop sidebar / mobile modal), карточка (SSR, JSON-LD, галерея, контакты, жалоба, «поделиться»), карта (Leaflet), создание/редактирование (каскад категорий, динамические характеристики, загрузка/порядок фото, точка на карте, черновик), избранное и сохранённые поиски, сообщения (WebSocket, статусы, вложения, архив, блокировка, офлайн-индикатор), профиль, публичный профиль продавца, профиль компании и создание, мои объявления (статусы, действия, статистика), заказы (покупки/продажи, действия, история, отзыв), оформление заказа, платежи/услуги/история операций, продвижение, тестовая страница оплаты, настройки (профиль, аватар, телефон, пароль, уведомления, сеансы, конфиденциальность, удаление), уведомления, справочный центр, вход/регистрация/подтверждение/восстановление, 404/ошибка. Скелетоны, пустые состояния, ошибки с повтором, диалоги подтверждения, валидация, доступность (skip-link, aria, focus-visible, reduced-motion).

### Admin (`apps/admin`)
17 разделов: обзор, модерация, жалобы, объявления, пользователи, компании, заказы, платежи (+ сверка счетов, возвраты), тарифы, категории (+ характеристики), характеристики, регионы, реклама, аналитика, журнал действий, безопасность, настройки (+ стоп-слова, переиндексация, очереди). Навигация по правам роли, доступ — на backend.

### Mobile (`apps/mobile`)
Вкладки (главная с рекомендациями, поиск с сортировкой/ценой и премиум-блоком, размещение объявления с фото и характеристиками, сообщения, профиль), карточка объявления (покупка через страницу оплаты, чат, звонок, избранное), чат в реальном времени, вход (email/SMS), регистрация, мои объявления, заказы, избранное. Refresh-токен в SecureStore, push-регистрация.

### Инфраструктура
Dockerfile API/worker и Next.js (web/admin), docker-compose (PostgreSQL, Redis, OpenSearch, SeaweedFS (S3), Mailpit, ClamAV, migrate, api, worker, web, admin, nginx, Prometheus, Grafana, Loki/Promtail), nginx, Helm-чарт (HPA, PDB, миграции hook'ом, ingress с allowlist админки, бэкап CronJob), GitLab CI (typecheck, unit, integration, integration на OpenSearch, E2E, сборка бандлов и образов, деплой), алерты Prometheus, дашборд Grafana, скрипты backup/restore.

## Известные ограничения и долги (явно)
- **Платежи и доставка — только тестовый режим.** ЮKassa-адаптер не проверен на реальном магазине; выплаты продавцам не реализованы (нужен провайдер со сплитованием — см. LEGAL.md §5).
- SMS.ru, Expo Push, ClamAV, SMTP-боевой — адаптеры без проверки с реальными ключами/сервисами.
- Нативные сборки iOS/Android (EAS), тесты на физических устройствах — не выполнялись.
- Нагрузочное тестирование и pentest — не выполнялись. **Production-ready не заявляется.**
- 2FA для сотрудников, WAF/капча — не реализованы.
- Интеграция с ОРД (отчётность по рекламе) и службами доставки — не реализована.
- Мобильное приложение: нет редактирования объявлений, фильтров по характеристикам, вложений в чате.
- UI-кит продублирован в web и admin (вынести в `packages/ui`).
- Юридические тексты в справочном центре — черновики.
